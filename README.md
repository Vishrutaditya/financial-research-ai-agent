# Financial Research AI Agent

An intelligent, Python-based financial research assistant designed to streamline market analysis. The application automates comprehensive stock evaluations, computes technical indicators, tracks real-time news sentiment, and compiles professional PDF research reports for investors and analysts. Deployed live on Streamlit.

## 🚀 Key Features

*   **Automated Stock Analysis:** Fetch key financial metrics, historical price data, and company fundamentals instantly.
*   **Technical Indicators:** Compute and visualize popular technical indicators (such as Moving Averages, RSI, MACD, etc.) to evaluate market trends.
*   **News Sentiment Tracking:** Analyze recent financial news headlines and articles to gauge market sentiment regarding specific tickers.
*   **PDF Report Export:** Compile all research findings, charts, and summaries into clean, exportable PDF reports for offline review.
*   **Interactive Web Interface:** Built with a user-friendly Streamlit dashboard for seamless query execution and data visualization.

## 🛠️ Tech Stack

*   **Core Language:** Python
*   **Web Framework & UI:** Streamlit
*   **Data & Analysis:** Pandas, NumPy, Financial Data APIs
*   **Document Generation:** ReportLab / FPDF (for PDF export)
*   **Version Control:** Git & GitHub

## 💻 Installation and Local Setup

Follow these steps to set up and run the project locally on your machine.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Vishrutaditya/financial-research-ai-agent.git](https://github.com/Vishrutaditya/financial-research-ai-agent.git)
Navigate to the project directory:

Bash
cd financial-research-ai-agent
Set up a virtual environment:

Bash
python -m venv venv
source venv/bin/activate  # On Windows use: venv\Scripts\activate
Install the dependencies:

Bash
pip install -r requirements.txt
🏃‍♂️ Usage
Start the Streamlit application locally by running:

Bash
streamlit run app.py
Once running, open your browser and navigate to the local URL provided in the terminal (typically http://localhost:8501) to interact with the AI research assistant.
